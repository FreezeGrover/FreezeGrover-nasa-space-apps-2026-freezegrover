# Scientific QA rules and limitations

Original observations, extracted metadata, interpretation, and hypotheses must remain distinguishable.

Current QA is an interface and conservative rule scaffold. It is not an autonomous scientific reviewer. No live generator or independent review model is configured. All evidence-dependent checks remain pending. Manual recheck honestly reports the missing evidence connection and records a local session note.

A future Verified result requires actual source support, matched experimental conditions, valid units, contradiction search, uncertainty review, and independent assessment. A citation URL alone is insufficient. A missing comparison baseline must withhold comparative conclusions. The preview shows an illustrative uncertainty explanation rather than pretending to analyze arbitrary edited claims.

Goal matching must not be described as hazard probability, measured safety, or validated habitat suitability. Catalog order is retained; no numeric rank is invented.
