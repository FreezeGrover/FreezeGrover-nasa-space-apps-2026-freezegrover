# Scientific QA rules and limitations

Original observations, extracted metadata, interpretation, and hypotheses must remain distinguishable.

Current QA is an interface and conservative rule scaffold. It is not an autonomous scientific reviewer. No live generator or independent review model is configured. All evidence-dependent checks remain pending. Manual recheck reports retrieved provenance and pending scientific checks, recording a local session note.

A future Verified result requires actual source support, matched experimental conditions, valid units, contradiction search, uncertainty review, and independent assessment. A citation URL alone is insufficient. A missing comparison baseline must withhold comparative conclusions. The preview shows an illustrative uncertainty explanation rather than pretending to analyze arbitrary edited claims.

Goal matching must not be described as hazard probability, measured safety, or validated habitat suitability. Catalog order is retained; no numeric rank is invented.

## Current PSI integration
Original metadata and 22 CSVs are now retrieved. QA can inspect per-record provenance and tables but does not equate successful ingestion with claim verification. The review function remains separate from answer generation and marks source-dependent checks pending. Claims, quantitative interpretations and rankings still require independent evidence and condition review. See PSI_CONNECTION.md.
